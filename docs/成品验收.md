## 正式页面及分享

- Chromium 逐人从首页完成四幕、24 题，经揭晓进入结果。核对主型姓名、第二接近和最不像、五维与两条选择证据；实际下载八张 1080 × 1440 PNG。[结果卡总览](嘉宾结果卡总览.jpg)
- WebKit 在 390px 移动尺寸、减少动效设置下，从答题到署名、导出、重测整条路径通过。Chromium 另验键盘作答、刷新续答、回看修改、复制配文、双击防重入、损坏存档。
- 对 320、375、390、768、1440px 五档宽度检查首页、信封页、题目页、结果页，均无横向溢出。[手机首页](../output/playwright/首页-手机.png) · [手机结果](../output/playwright/回信-手机.png)
- 旧版完整答卷不会在新版显示成嘉宾结果。独立 HTML 移到单独目录、浏览器断网后，从头完成 24 题并生成 PNG，加载记录只有 HTML 本身。
- 测试域名子路径下实际导出的二维码，已从 PNG 解码回相同入口。本机或离线成品使用邮戳。微信长按菜单及原生系统分享尚待真机体验。

结果页首屏改版后，重新从首页走完八条路径，核对嘉宾回信、两条实选依据与首屏按钮，下载八张 PNG。Chromium 与 WebKit 实测了修改收件人、回车更新、清空恢复默认称呼；对比导出图收件人区域的像素确认改名生效。另验断网独立 HTML 的整套流程。[结果首屏](../output/playwright/结果首屏-手机.png) · [明信片预览](../output/playwright/明信片预览-手机.png)
