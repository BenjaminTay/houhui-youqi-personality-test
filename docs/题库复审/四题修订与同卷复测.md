# 四题修订与同卷复测 · 2.2

2026 年 11 月 24 日。24 题中的 5、6、19、20 题有改动。逐项比对确认其余 20 题相同，正式计分实现和八人的原型数据与 2.1 逐字节一致。2.2 使用独立的浏览器存档，首次进入从第一题开始。

## 四道题改了什么

| 题 | 修订依据与选择 | 计分处理 |
| --- | --- | --- |
| 05 介绍给新朋友 | 原题只问如何认识，讲一段相识往事天然更切题。现在请读者介绍身边的旧友，从共同经历、关系变迁、当下话题、目前交情开口都能回答。 | 沿用四个选项的旧事／关系分值。 |
| 06 车站接人 | 将合力抬出卡住的箱子写进题干，所有答题者都已帮忙。再选听近况、带点心并约下次、开口邀约、整理箱带并送到出口。B 与 D 区分提前惦记和当场照应。 | 沿用破冰／心意／下次分值。共同的抬箱动作不参与区分，计分对应脱困后的下一步。 |
| 19 那句算和好吗 | C 和 D 都对重逢表达善意。C 已决定偶尔问候、维持普通朋友的距离；D 想再相处一阵，仍在形成决定。 | C 保持 [1,5]，D 的下次／关系由 [2,2] 改为 [3,2]。正式贡献中 C 更偏王子璇，D 在厉娜与王子璇之间偏厉娜；D 放入全部八型时对白小纯的贡献最高。 |
| 20 没约成的周六 | 旧题与第 3 题的四组分值同构。新情境是重联后的邀约被婉拒，四种接法分别为另提日期、询问上次的经历、换成两人熟悉的低压力活动、接受这次落空并把邀约留给对方。 | 改测破冰／旧事／下次。四项最高贡献依次为张萌、文吉儿、青稚、马天宇，并只作为整张答卷的一部分。 |

第 20 题的事实依据是张萌曾邀请马天宇合作，马天宇婉拒，两人在节目中回顾了这次邀约带来的分歧。公开节目复盘支持这一冲突背景。周六看展、面馆、重复相约及四种回话均为日常化改写。四个选项体现的处理方式来自本测试的原型解释。[澎湃号刊载的节目复盘](https://www.thepaper.cn/newsDetail_forward_34352441) · [Tatler 对该段情节的复盘](https://www.tatlerasia.com/lifestyle/entertainment/i-miss-you-reality-show-review-zh-hans)

## 同一批答卷的结果

种子 20261124。将每份答卷的 24 个选项 ID 原样传给两个正式分类器。前 100,000 份每题均匀随机；另 40,000 份完全按 **2.1 的原型**生成，每人 5,000 份，每题有 75% 的机会从旧版最近选项中抽取，25% 从全部选项中抽取。对照脚本重现了 2.1 快照的 28 对排名统计和全部八行偏型去向。100,000 份中有 17,368 份的主型改变。第 20 题已替换，固定字母可测版本改动的影响，无法据此推断同一个人读完新题后仍会选相同字母。

## 复现

从项目根目录运行下列命令。第二次诊断会读取指定的旧题库与旧模型，生成完全配对的答卷，并同时计算两个版本的结果。

```sh
baseline_dir=$(mktemp -d)
unzip -q docs/题库复审/2.1复现源码.zip -d "$baseline_dir"
node tests/collisions.js
node tests/collisions.js "$baseline_dir"
npm test
npm run diagnose
npm run build
```
