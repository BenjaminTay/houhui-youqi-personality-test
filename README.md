# 后会友期 · 旧友邮局

一款受《后会友期》旧友重逢主题启发的原创娱乐测试。拆开四封来信，回答 24 道日常情境题，测出你最像《后会友期》里的哪位同行嘉宾。

**直接体验**　[打开旧友邮局](https://benjamintay.github.io/houhui-youqi-personality-test/) · [独立 HTML 版](https://benjamintay.github.io/houhui-youqi-personality-test/旧友邮局.html)。独立版可另存后离线使用，包含封面、字体、题库、计分和 PNG 导出。

## 网站里有什么

- 四封来信分别写旧友重新联系、旅途同行、摊开旧事和告别后的联系。首页邮票可先拆读，问卷按次序推进。
- 八种结果对应张萌、马天宇、许飞、厉娜、文吉儿、王子璇、青稚、白小纯。每张卡写出最像的嘉宾、第二接近和最不像的人。结果首屏在嘉宾姓名下展示一封原创短回信和一条实选依据。继续阅读可查看节目材料、五维刻度和另一条实选依据。
- 支持返回修改、刷新续答、回看结果、署名和重测。内容保存在当前浏览器，网站本身没有统计 SDK。
- 在结果首屏点「保存我的明信片」可直接预览同一句回信。展开「修改收件人」可更新卡面，默认收件人为「久别重逢的我」。明信片导出为 1080 × 1440 PNG。可下载或长按预览图保存，浏览器支持文件分享时也可调用系统分享。正式 HTTP(S) 站点会印上当前入口的二维码，本机和离线版使用原创邮戳。

## 本地开发

使用 Node.js 22，执行以下命令。

```sh
npm ci
npm run dev
npm test
npm run diagnose
npm run --silent audit:collisions
npm run build
npm run preview -- --port 4186
```

`dist/` 可放入静态站点根目录或子路径，其中 `index.html` 用于常规托管，`旧友邮局.html` 可独立分发。服务端无需保存答案。需要从同一局域网进行手机真机试玩时，可在可信网络用 `npm run preview -- --host 0.0.0.0` 启动，用手机访问该电脑的局域网地址。
